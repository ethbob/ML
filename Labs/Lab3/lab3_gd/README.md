## Что сделано (по пунктам задания)

1. **Датасет:** `make_regression` — 1000 объектов, 5 признаков (3 информативных, 2 «мусорных»), свободный член 50, шум 15.
   Итого 6 весов. Признаки стандартизированы `StandardScaler`, добавлен столбец единиц для свободного члена.
2. **Градиентный спуск** написан вручную строго по алгоритму: начальные веса и ε → цикл →
   `w = w − η·∇Q(w)`, где `∇Q = 2/n · Xᵀ(Xw − y)` → стоп при `‖wᵏ − wᵏ⁻¹‖ < ε`.
   Результат совпал с `LinearRegression` до 4 знаков.
3. **Скорость обучения** η ∈ {0.001, 0.01, 0.1, 0.5, 0.9, 1.05}: маленькая — медленно (5000+ итераций),
   0.5 — 8 итераций, 0.9 — колебания и замедление, 1.05 — расходится.
4. **Стохастический спуск:** в ту же функцию добавлен параметр `stochastic=True` — градиент по одному
   случайному объекту `2·xᵢ(xᵢw − yᵢ)` и затухающий шаг `ηₖ = η₀ / (1 + decay·k)`.
5. **GD vs SGD** на одном графике: GD — 76 гладких итераций, SGD — тысячи шумных, но по объёму вычислений
   (сколько объектов обработано) SGD снижает ошибку быстрее.
6. **L1-регуляризация** (вариант 4 — чётный): `Q = MSE + λ·Σ|wⱼ|`, реализована проксимальным шагом
   (soft thresholding), проверена по `sklearn.Lasso`. 20 значений λ от 0.001 до 1000 (`np.logspace(-3, 3, 20)`):
   сначала обнуляются бесполезные признаки x4 и x1, затем полезные; при λ ≥ ~110 все веса признаков равны 0.

## Теория для защиты (коротко)

- **Градиент** — вектор частных производных функции потерь по весам; указывает направление наискорейшего роста ошибки.
  Спуск идёт в противоположную сторону.
- **Скорость обучения η** — размер шага. Маленькая — медленно, большая — перескакивает минимум и расходится.
- **GD** считает градиент по всей выборке (точно, дорого), **SGD** — по одному объекту (шумно, дёшево).
  Компромисс — **мини-батчи** (градиент по небольшой группе объектов).
- **Регуляризация** штрафует за большие веса, борется с переобучением.
  **L1 (Lasso)** — штраф `λ·Σ|w|`, обнуляет веса → отбор признаков.
  **L2 (Ridge)** — штраф `λ·Σw²`, только уменьшает веса, не обнуляя.
- **Масштабирование** нужно, потому что при признаках разного масштаба «безопасный» шаг для одного признака
  слишком велик для другого.
