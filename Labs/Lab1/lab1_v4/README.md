# Часть 1. Встроенные типы данных

Основные типы Python:

| Тип | Пример | Изменяемый? | Для чего |
|---|---|---|---|
| `int`, `float` | `5`, `3.14` | нет | числа |
| `str` | `"текст"` | нет | строки, последовательность символов |
| `list` | `[1, 2, 3]` | **да** | упорядоченный набор, можно менять |
| `tuple` | `(1, 2, 3)` | нет | как список, но неизменяемый |
| `dict` | `{"a": 1}` | **да** | пары «ключ → значение», быстрый поиск по ключу |
| `set` | `{1, 2, 3}` | **да** | уникальные элементы без порядка |

**Срезы** `seq[start:stop:step]` работают у строк, списков и кортежей:
`s[::-1]` переворачивает, `lst[1::2]` берёт каждый второй элемент, начиная с индекса 1.

### Задание 1. Сумма цифр натурального числа
Проверяем ввод через `isdigit()`: все символы должны быть цифрами, а число больше 0.
Дальше показаны два способа:
- **строковый**: строка `"12345"` уже состоит из цифр-символов, проходим по ней и суммируем `int(ch)`;
- **арифметический**: `n % 10` даёт последнюю цифру, `n //= 10` её отбрасывает, повторяем, пока `n > 0`.

### Задание 2. Слова-палиндромы
`split()` делит строку на слова. У каждого слова убираем знаки препинания (`strip`) и регистр (`lower`).
Слово считается палиндромом, если `clean == clean[::-1]`. Однобуквенные слова (`а`, `и`) не учитываем,
потому что они палиндромы тривиально.
Пример: «На шалаше казак и дед, а потоп...» → `казак, дед, потоп`.

### Задание 3. Операции со списком
- **Произведение элементов с нечётными номерами.** Индексы в Python начинаются с 0,
  поэтому нечётные номера это индексы 1, 3, 5… Их берёт срез `nums[1::2]`.
  *Если преподаватель считает номера с 1 (1-й, 3-й, 5-й элемент), замени срез на `nums[0::2]`.*
- **Удалить наибольший.** `max()` находит значение, `remove()` удаляет его первое вхождение.
  Перед этим делаем `copy()`, чтобы исходный список пригодился для следующего пункта.
- **Три наибольших.** `sorted(..., reverse=True)[:3]`: сортируем по убыванию и берём первые три.

### Задание 4. Словарь из двух списков
Сначала проверяем, что длины списков совпадают. Словарь строим двумя способами:
вручную циклом по индексам и короче, через `dict(zip(keys, values))`.
`zip` склеивает списки попарно: `zip([a,b], [1,2])` → `(a,1), (b,2)`.
Если в первом списке есть повторы, ключей станет меньше, потому что ключи словаря уникальны.

### Задание 5. «Ювелирный магазин»
Данные хранятся в словаре: `название → [состав, цена, количество]`.
Меню крутится в цикле `while True` и выходит через `break` на пункте 6.
В «Покупке» вводим название и количество, пока не введём `n`. Каждый выбор проверяется:
есть ли такое изделие, целое ли и положительное количество, хватает ли товара в наличии.
Остаток уменьшается прямо в словаре, в конце выводятся чек, итоговая сумма и остатки.
Константы `DESCRIPTION, PRICE, COUNT = 0, 1, 2` нужны, чтобы вместо `info[2]` писать понятное `info[COUNT]`.

### Задание 6. Кортеж из 10 случайных чисел
Кортеж нельзя изменить после создания, поэтому собираем его сразу:
`tuple(random.randint(1, 100) for _ in range(10))`. Максимум и минимум находят `max()` и `min()`.

# Часть 2. Функции и исключения

**Функция** это именованный блок кода: `def имя(параметры): ... return результат`.
Если `return` нет, функция возвращает `None`.
`isinstance(x, тип)` проверяет тип значения, на этом построено задание 2.

**Исключение** это ошибка во время выполнения (`ValueError`, `ZeroDivisionError` и т. п.).
Если её не обработать, программа падает.

### Задание 1. `prime(n)`: n-е простое число
Вспомогательная `is_prime(x)` ищет делители только до √x: если у числа есть делитель больше корня,
в паре с ним обязательно есть делитель меньше корня. `prime(n)` перебирает числа подряд и считает
простые, пока не найдёт n-е. Нумерация с 1: `prime(1) = 2`, `prime(10) = 29`.

### Задание 2. Одна функция для разных типов
Функция `analyze(value)` проверяет тип цепочкой `isinstance` и делает своё для каждого:

| Тип | Что делаем | Как |
|---|---|---|
| `dict` | ключ с минимальным значением | `min(d, key=d.get)`: сравниваем ключи по их значениям |
| `list` | произведение между первым и вторым нулём; удаление повторов | находим индексы нулей, берём срез между ними; `list(dict.fromkeys(lst))` убирает повторы и сохраняет порядок |
| `int` | все делители | перебор `d` от 1 до n, где `n % d == 0` |
| `str` | палиндром? гласные и согласные | оставляем только буквы, сравниваем с перевёрнутой строкой; гласные ищем в множестве `VOWELS` |

`bool` отсекается отдельно, потому что в Python `True` тоже является `int`.
В `task2` функция вызывается на наборе примеров всех типов, как требует задание («сделать проверку со всеми случаями»).

### Задание 3. Суммы строк матрицы m×n
Матрица представлена списком списков: каждая строка это отдельный список.
Сумму строки считает `sum(row)`, для всех строк `[sum(row) for row in matrix]`.
Матрицу можно ввести вручную или заполнить случайно вложенным генератором.

### Задание 4. `try / except / finally`
```
try:      код, где может случиться ошибка
except X: выполняется, если случилась ошибка типа X
else:     выполняется, если ошибки НЕ было
finally:  выполняется ВСЕГДА (обычно тут закрывают файлы и соединения)
```
Функция `safe_divide` показывает три сценария: нормальное деление, деление на ноль
и ввод не числа. Во всех трёх случаях `finally` выполняется.

# Часть 3. ООП

| Понятие | Смысл |
|---|---|
| **Класс** | шаблон, описание: какие данные и действия будут у объектов |
| **Объект (экземпляр)** | конкретная вещь, созданная по шаблону: `sq = Square(5)` |
| **`__init__`** | конструктор, вызывается при создании объекта |
| **`self`** | ссылка на текущий объект внутри методов |
| **Инкапсуляция** | данные скрыты (`self.__x`), доступ только через методы |
| **Наследование** | `class Pen(Stationery)`: дочерний класс получает всё от родителя |
| **Полиморфизм** | один вызов `obj.draw()` ведёт себя по-разному в зависимости от класса объекта |

### Задание 1. `Square`
Сторона хранится в `self.side`. Методы: периметр `4a`, площадь `a²`, диагональ `a·√2`
(по теореме Пифагора `d² = a² + a²`). Конструктор не пускает сторону ≤ 0.

### Задание 2. `Stationery` → `Pen`, `Pencil`, `Handle`
Базовый класс хранит `title` и метод `draw()` с сообщением «Запуск отрисовки».
Каждый наследник **переопределяет** `draw()` своим сообщением. `Handle` дополнительно вызывает
`super().draw()`: сначала выполняется родительская версия, потом своя.
В `task2` у всех объектов в цикле вызывается один и тот же `draw()`, это и есть полиморфизм.

### Задание 3. `Faculty` и `Student`
- Поля закрытые (`self.__name`). Для каждого есть **геттер** `get_...()` и **сеттер** `set_...()`,
  как требует задание («методы доступа и изменения всех полей»).
- Сеттеры проверяют данные: год рождения в разумных пределах, оценки от 0 до 10, факультет является объектом `Faculty`.
  Конструктор тоже записывает поля через сеттеры, поэтому проверка работает сразу.
- Студент **содержит** объект `Faculty`. Это композиция: связь «у студента есть факультет».
- Успеваемость: средний балл, список долгов (оценка < 4 по 10-балльной шкале) и статус
  (отличник: все ≥ 9, хорошист: все ≥ 6, успевает, есть задолженности).
- Программа считывает студентов с клавиатуры (Enter подставляет демо-данные), выводит отчёт
  и показывает сеттер в действии: пересдачу экзамена через `set_grade`.

### Задание 4. Свой класс `Temperature`
Три вида методов:

| Вид | Декоратор | Первый параметр | Когда использовать | В классе |
|---|---|---|---|---|
| метод экземпляра | нет | `self` (объект) | нужны данные конкретного объекта | `to_fahrenheit()`, `to_kelvin()`, `describe()` |
| статический | `@staticmethod` | нет | функция по теме класса, которой не нужны ни объект, ни класс | `c_to_f()`, `f_to_c()` |
| метод класса | `@classmethod` | `cls` (класс) | работа с атрибутами класса, альтернативные конструкторы | `from_fahrenheit()`, `from_kelvin()`, `created()` |

Атрибут класса `count` общий для всех объектов и считает, сколько их создано.
